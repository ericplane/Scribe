# Build something

Choose the feature you need. You do not need to read every guide to use Scribe.

If this is your first visit, complete [Getting Started](./intro) first. It gives you a working shared data module and scripts for the server and client. Most feature guides then use the larger [Emberfall template](./emberfall); copy the fields you need into your own template.
