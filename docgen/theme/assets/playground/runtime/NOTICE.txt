The local loader is adapted from upstream src/index.js: it always selects the
Asyncify build and uses local .mjs import names. One worker-environment refusal
assertion is removed from the generated Asyncify host script; its existing
DOM-free WEB||WORKER branch is used. The embedded WebAssembly payload is unchanged.
These adaptations do not change Scribe's validation or accessor behavior.
